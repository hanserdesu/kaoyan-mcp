## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### Dijkstra 逐轮表格（S · S-过程）
- **L1** 认出"单源 + 非负权"适用前提，记住 dist/path/已确定集合三个数组的含义（DS-06-001）
- **L2** 单轮演练：给定当前 dist，选出本轮确定顶点（未确定集中 dist 最小）并松弛其邻接点（DS-06-002/003）
- **L3** 多轮完整手算：n−1 轮表格每轮输出确定顶点+完整 dist/path 行，结束读出最短路长与路径（DS-06-004/005）
- **L4** 边界与陷阱：负权边使"已确定顶点的 dist 可能再变小"，贪心失效——不适用负权图（参考章末「常见问题和易混淆知识点」@p269-270）
- **L5** 跨章串联：与 DS-06-031（BFS 无权最短路）并置辨析；与关键路径共用"表格逐步给分"的大题风格
- **预期变形**：要求写出第 3 轮的 dist/path（只给中途态）；换源点重算；问某顶点何时进入已确定集合
- **陷阱**：把松弛写成"只比较不更新"；漏更新 path 前驱；把"本轮确定的顶点"与"本轮被松弛的顶点"混淆

### Floyd 矩阵迭代（S · S-过程）
- **L1** 记住 A^(k) 的含义：允许经过编号不超过 k 的顶点中转（DS-06-006）
- **L2** 单层演练：给 A^(0)（直接距离矩阵），算 A^(1)（允许经 1 号点中转）（DS-06-007）
- **L3** 多层迭代：逐 k 写 A^(1)、A^(2)…，配合 path 矩阵记录中转点并还原路径（DS-06-008）
- **L4** 边界与陷阱：可含负权边、不可含负权回路；迭代必须"本轮全部用上一轮的值"，原地更新会引入错误（参考 6.4.7 解析@p264-266 与章末@p269-274）
- **L5** 跨章串联：与 DS-06-001～005 并置考"Dijkstra vs Floyd 适用性"
- **预期变形**：给 A^(0) 求 A^(1) 或 A^(2)；问迭代 k 层后某对顶点距离；按 path 还原路径
- **陷阱**：把"中转点编号"与"迭代轮数"混淆；对角线被误更新；负权边与负权回路混为一谈

### 拓扑排序（S · S-过程）
- **L1** 识别 AOV 网（DAG），记住"拓扑序列存在 ⇔ 无环"（DS-06-009）
- **L2** 单步演练：从入度表选出入度 0 顶点输出，删边并给邻接点入度 −1（DS-06-010）
- **L3** 全程手算：完整拓扑序列；入度 0 顶点多于一个时枚举全部序列个数（DS-06-011）
- **L4** 边界与陷阱：栈/队列都合法（只影响顺序）；输出顶点数 < n 即有环、排序失败；逆拓扑用 DFS 退栈逆序（DS-06-020，参考章末@p273-274）
- **L5** 跨章串联：与 DS-06-012（AOE 网）构成大题连续体；代码层见 C-DS-06-08
- **预期变形**：给序列判断是否合法拓扑序；数拓扑序列个数；判环
- **陷阱**：漏减某条出边的入度；把"入度 0"写成"出度 0"；认为栈与队列结果有一者非法

### 关键路径四表联动（S · S-过程）
- **L1** 识别 AOE 网（顶点=事件、弧=活动），记住源/汇与"关键路径 = 最长路径"（DS-06-012）
- **L2** 单表演练：给定拓扑序，算 ve（源点 0，逐点取所有入边 max）（DS-06-013）
- **L3** 多表联动：逆拓扑序算 vl（汇点出发逐点取 min）→ 活动 e/l/d 表 → 圈出 d=0 关键活动（DS-06-014/015/016）
- **L4** 边界与陷阱：关键路径可多条；缩短单个关键活动不一定缩短工期（须缩短所有关键路径共有活动）；关键活动延误必延误工期（参考章末@p269-270）
- **L5** 跨章串联：与 DS-06-009～011 共用拓扑序（ve 按拓扑序、vl 按逆拓扑序）
- **预期变形**：问工期与关键活动集合；问"缩短活动 a 能否缩短工期"；问某事件的最迟发生时间
- **陷阱**：ve 用 min、vl 用 max（方向记反）；把活动最早开始写成弧头事件的 ve

### MST 过程（Prim/Kruskal）（S · S-过程）
- **L1** 识别带权连通无向图 + 生成树目标（n−1 条边）（DS-06-017）
- **L2** 单步演练：Prim 从起点选第一条最小横跨边；Kruskal 排序后取第一条不成环边（DS-06-018/019）
- **L3** 全程手算：Prim 逐步扩展树内点集；Kruskal 逐步取边并判连通性
- **L4** 边界与陷阱：权互异 → MST 唯一，反之未必；Prim 只在"树内→树外"横跨边中选（不是全图最小边）；Kruskal 成环边直接跳过（参考章末@p269-270）
- **L5** 跨章串联：Kruskal 判环 = 第 5 章并查集；边排序 = 第 8 章排序（见 C-DS-06-14）
- **预期变形**：问第 k 步选中的边；问 MST 权值和；给两个命题判 MST 唯一性真假
- **陷阱**：Prim 把树内点之间的边又选进来；Kruskal 忘判环；一见等权就判"MST 必不唯一"

### 存储结构四件套（A · S-概念 / S-结构 / S-辨析）
- **L1** 说出四种存储的名称与适用图类：十字链表=有向、邻接多重表=无向（DS-06-022～028）
- **L2** 给定图写出邻接矩阵/邻接表；数出边数与某点度
- **L3** 空间与操作代价：矩阵 O(n²)、判边 O(1)、数边全扫；表 O(n+e)/O(n+2e)、判边要遍历边表
- **L4** 边界与陷阱：邻接矩阵唯一、邻接表不唯一（建表次序）；有向图邻接表求入度难（需逆邻接表）（参考章末@p269-274）
- **L5** 跨章串联：遍历复杂度（DS-06-034）与存储选择直接挂钩；算法设计题代码基于邻接表

### 图的遍历 BFS/DFS（A · S-过程）
