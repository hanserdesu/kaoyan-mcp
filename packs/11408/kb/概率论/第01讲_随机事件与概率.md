## 二、本书定位（考点 / 题型 / 目标 / 重难点）

- **本讲无考纲表**（张宇概率分册只给"基础知识结构"导图，无高数册那样的考点/题型/目标表）。
- **考点（据真题档案"1 事件与概率"两行）**：① 条件概率、独立性判定（年频选择：互斥≠独立、$P(AB\mid C)$ 变形）；② 全概率 + 贝叶斯（隔年，大题 occasionally 与一维分布结合）。
- **讲目标**（读自 p10-p11 导图两页 + 正文）：建立随机事件符号语言（关系与运算）→ 会算两类概型（古典 / 几何）→ 掌握概率性质与全套公式（逆 / 减 / 加 / 条件 / 乘 + 全概率 / 贝叶斯）→ 独立性判定与 n 重伯努利。
- **题型**：选择（概念辨析：互斥≠独立、对立与互斥、两两 vs 相互）、填空 / 解答（古典几何计数、全概率两层试验、伯努利"至少一次"）。
- **重难点**：① 全概率公式的**全集分解**建模（找到完备事件组是唯一入口）；② 独立性判定（两两 vs 相互、互斥 vs 独立）。
- **全库定位**：本讲是后续每一讲的**事件语言地基**——第 2 讲 $F(x)=P\{X\le x\}$、第 2 讲混合型的全概率分解（GL-02-003）、第 3 讲条件分布与二维独立性，全部调用本讲原子。

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 全概率公式与全集分解（A · M-建模）——本讲最高优先
- **L1** 识别完备事件组：两两互斥 + 并为 $\Omega$（GL-01-012）；把"结果 B"与"原因 $A_i$"分层写
- **L2** 套全概率公式 $P(B)=\sum_i P(A_i)P(B\mid A_i)$：先验与条件概率各就各位
- **L3** 贝叶斯反推 $P(A_j\mid B)$：分子 = 先验 × 条件，分母 = 全概率值（"执果索因"）
- **L4** 边界：完备组不互斥 / 漏事件则公式失效；两层试验的第一层概率随抽样方式变（有放回 / 无放回，GL-01-020）
- **L5** 跨讲串联：GL-02-003（第 2 讲，混合型密度的全概率分解）、第 3 讲条件分布
- **预期变形**：先分组再取、两箱互换（习题1.18）、双完备事件组（习题1.19）、装错信
- **陷阱**：① 漏乘先验 $P(A_i)$；② 把 $P(B\mid A)$ 当 $P(AB)$（GL-01-001）；③ 完备组找不全就硬套公式

### 独立性判定（A · M-概念）
- **L1** 定义式 $P(AB)=P(A)P(B)$ 及其语义（"互不影响"）
- **L2** 等价形式与对立封闭（$A,B$ 独立 ⇒ $\bar A$ 与 $B$ 等仍独立，GL-01-007）
- **L3** $n=3$ 相互独立的 4 条件；两两独立反例（例1.13 型，GL-01-006）
- **L4** 边界：互斥 ≠ 独立（$0<P(A)<1$ 且 $0<P(B)<1$ 时互斥必不独立）；$P(A)=0$ 或 1 与任何事件独立
- **L5** 跨讲串联：GL-02-008（第 2 讲，方差可加需独立）、第 3 讲二维独立性；顺独立试验序列延伸到 GL-01-008（n 重伯努利）
- **预期变形**：给联合分布表判独立（第 3 讲皮）、"加条件后是否仍独立"、独立性封闭运算判断
- **陷阱**：① 把两两独立当相互独立；② 把 $P(A\cup B)=P(A)+P(B)$ 当独立判据（那是互斥）；③ 对立封闭的方向说反

### 条件概率与乘法公式（A · M-计算）
- **L1** 定义式 $P(B\mid A)=\dfrac{P(AB)}{P(A)}$：样本空间收缩到 $A$ 上
- **L2** 乘法链展开 $P(ABC)=P(A)P(B\mid A)P(C\mid AB)$（GL-01-002）
- **L3** $P(AB\mid C)$ 类恒等变形（档案年频选择）
- **L4** 边界：$P(A)=0$ 时条件概率无定义；同一条件下逆事件 $P(B\mid A)+P(\bar B\mid A)=1$；条件概率 ≠ 减法公式 $P(A-B)$
- **L5** 跨讲串联：第 3 讲条件分布 $f_{X\mid Y}$（同一除法结构的密度版）
- **预期变形**：混入容斥的多事件恒等式、与全概率互逆的两问结构（先正推后反推）
- **陷阱**：① 分母写成 $P(B)$；② 把"在 $B$ 发生的条件下"读成 $P(AB)$；③ $P(A\mid B)$ 与 $P(B\mid A)$ 方向颠倒
