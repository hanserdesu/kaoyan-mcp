- **本讲无考纲表**：张宇概率分册只给"基础知识结构"导图，无高数册那样的考点/题型/目标表（与第 1、2 讲一致）。

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：**知识级推演**（建模期归纳），非实测。

### 数字特征族的"不对称"辨析（S · M-概念）——**最高优先**
- **L1** 说清四个数字特征各反映什么：$EX$ 位置（加权平均）、$DX$ 散度、$\mathrm{Cov}$ 关联、$\rho$ 线性相关程度
- **L2** 三条规则的成立条件：$E(aX+bY)=aEX+bEY$（无条件）、$E(XY)=EXEY$（需独立）、$D(X+Y)=DX+DY$（需独立/不相关）
- **L3** 换条件：仅"不相关"（不独立）时 $D(X+Y)=DX+DY$ 是否仍成立？成立。$E(XY)=EXEY$ 呢？也成立
- **L4 边界**：$\mathrm{Cov}(aX,bY)=ab\,\mathrm{Cov}$（不带平方）vs $D(aX)=a^2DX$（带平方）——方向相反，专考混淆
- **L5** 跨讲串联：GL-02-006/008（第 2 讲挂账收口）→ GL-04-030 → 第 3 讲联合分布
- **预期变形**：$D(X_1+X_2+\cdots)$ 多变量展开（两两协方差全都要写）、由 $D(X\pm Y)$ 反求 $\mathrm{Cov}$
- **陷阱**：① 把 $E(XY)=EXEY$ 当无条件；② 方差可加不查独立性；③ $\mathrm{Cov}$ 展开丢 $2\mathrm{Cov}$；④ 相关系数分母写成 $DX\cdot DY$

### 方差计算式与 $E[g(X)]$（S · M-计算）——**第二优先**
- **L1** 双式子：$DX=E[(X-EX)^2]=E(X^2)-(EX)^2$（能自己展开推一遍）
- **L2** 免求分布直接算 $E(X^2)=\int x^2f(x)dx$（**不要先求 $X^2$ 的密度**）
- **L3** 换场景：$E(\lvert X-EX\rvert)$（例 4.5）、$E(e^{-2X})$（习题 4.6）、$D(e^{-2X})$
- **L4 边界**：$DX\le E[(X-c)^2]$（$c=EX$ 最小）；$D(X^2)$ 需先求 $X^2$ 的分布或分布律（习题 4.5）
- **L5** 跨讲串联：GL-02-004/005（第 2 讲）→ 第 3 讲二维期望
- **预期变形**：由 $DY$ 与 $EY$ 反求 $E(Y^2)$；形如 $Ae^{-ax^2+bx+c}$ 的密度先配方法读出 $\mu,\sigma^2$ 再算
- **陷阱**：① 先求 $Y=g(X)$ 分布再积分（费时且易错）；② $D(aX+b)$ 写成 $aDX$；③ 密度未归一就套公式

### 协方差与相关系数（S · M-计算）——**第三优先**
- **L1** 定义式两条：$\mathrm{Cov}=E[(X-EX)(Y-EY)]=E(XY)-EX\cdot EY$
- **L2** 解题次序（书旁注）：**先求 $EX,EY,E(XY)$**，再代入
- **L3** 由联合分布律表算 $E(XY)$（离散，例 4.7）/ 二重积分（连续，例 4.8）
- **L4 边界**：$\lvert\rho\rvert\le1$；$\rho=\pm1\Leftrightarrow P\{Y=aX+b\}=1$（**几乎处处**，不是"恒等"）；前提 $DX>0,DY>0$
- **L5** 跨讲串联：GL-04-020（二维期望）→ 第 3 讲联合/边缘分布
- **预期变形**：构造新组合变量 $U=X+Y,V=X-Y$ 求 $\rho$（例 4.9）；二维正态下由已知 $\rho$ 推新 $\rho$（习题 4.2）
- **陷阱**：① 分母写成 $\sqrt{DX\cdot DY}$ 与 $\sqrt{DX}\sqrt{DY}$ 的区别（数值同、但根号内乘积写成 $\sqrt{DXDY}$ 时最容易算错）② 忘了 $\mathrm{Cov}$ 需要 $E(XY)$ 这个"第三方"量

### 独立性与不相关性的判定（S · M-概念）——**第四优先**
- **L1** 独立用**分布**判（$F=F_XF_Y$ / $f=f_Xf_Y$ / $p=p\cdot p$）；不相关用**数字特征**判（$\mathrm{Cov}=0$）
- **L2** 三条等价链：$\rho=0\Leftrightarrow\mathrm{Cov}=0\Leftrightarrow E(XY)=EXEY\Leftrightarrow D(X\pm Y)=DX+DY$
- **L3** 判定流程：先算 $\mathrm{Cov}$ → $\ne0$ 即"相关 ⇒ 不独立"；$=0$ 则回查分布决定独立与否
- **L4 边界**：**独立 $\Rightarrow$ 不相关（反之不然）**；仅在**二维正态**下等价；反例 $Y=\cos X$（$\rho=0$ 却有函数关系）
- **L5** 跨讲串联：第 3 讲（二维正态、联合分布）；本讲 GL-04-027
- **预期变形**：形如"$X$ 与 $\lvert X\rvert$ / $X$ 与 $X^3$ / $X$ 与 $\cos X$"的关系判断（例 4.10、习题 4.4）
- **陷阱**：① 把"不相关"当成"独立"；② 用 $\rho$ 判定时忘了先确认 $DX,DY$ 存在且非零；③ 四选项中把"独立且不相关"当唯一正确

### 期望的存在性（A · M-概念）
- **L1** 定义里的"绝对收敛"不是摆设：$\sum\lvert x_i\rvert p_i<\infty$ 或 $\int\lvert x\rvert f(x)dx<\infty$
- **L2** 柯西分布 $f=\frac{1}{\pi(1+x^2)}$：$\int x f\,dx$ 发散 ⇒ $EX$ 不存在
- **L3** 判断陷阱：$\int_{-\infty}^{+\infty}$ 的"对称抵消为 0"只在绝对收敛时合法
- **L4 边界**：$EX$ 不存在的分布谈不上 $DX$、更谈不上切比雪夫
- **L5** 跨讲串联：GL-04-033（切比雪夫前提）
- **陷阱**：① 直觉说"对称所以期望为 0"；② 忽略"期望不存在"是一种正确答案（选择题选项）

### 常用分布 E/D 表（S · M-记忆）
- **L1** 七行公式张口就来（0-1 / 二项 / 泊松 / 几何 / 正态 / 均匀 / 指数）
- **L2** 用"参数—位置—散度"三条线记忆（正态的 $\mu,\sigma^2$ 直接对应；均匀看区间端点；指数 $1/\lambda$ 与 $1/\lambda^2$）
- **L3** 变形：泊松 $\lambda$ 的意义（$E=D=\lambda$）、几何 $E=1/p$ 与指数 $E=1/\lambda$ 的连续-离散对偶
- **L4 边界**：**泊松 vs 指数**（书上已手写划线提醒）——同一 $\lambda$ 的两种分布，一个计数一个等待
- **L5** 跨讲串联：GL-02-016（泊松）、GL-02-018（几何）、GL-02-021（指数）、GL-02-025（0-1）
- **陷阱**：① 几何方差写成 $\frac{1-p}{p^2}$ 与 $\frac{p}{1-p}$ 的混淆；② 均匀方差漏平方；③ 三 E 记号（$e$ / $E(\lambda)$ / $E(X)$）混淆（见 GL-02-035）
