```
│   ├── 中断与异常：外中断（可屏蔽/不可屏蔽）｜异常（故障/自陷/终止）

```

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。陷阱优先引用章末"本章疑难点"@p47-48 与各节解析实际页。

### 用户态/内核态切换途径（S · S-概念）
- **L1** 记住方向规则：用户→内核靠中断/异常；内核→用户靠返回指令
- **L2** 给定事件（系统调用/IO 完成/除零）判断是否发生态切换及方向
- **L3** 判断假命题："改 PSW 切态""中断处理程序切用户进内核"（1.3.6-07：PSW 指令本身特权）
- **L4** 边界：访管指令用户态可执行（不是特权指令，1.7③@p48）；内核态可执行完整指令集（1.3.6-11）
- **L5** 跨章串联：第 2 章进程切换（OS-01-036）、第 3 章缺页异常（OS-01-003）
- **预期变形**：给一段用户程序伪码问哪行触发切态；把"唯一途径"换成"有两种途径"设错
- **陷阱**：把系统调用的"发生"与"执行"混为一谈；认为中断发生时 CPU 一定已在内核态（2024 反例）

### 态切换四情形与判别（S · S-辨析）
- **L1** 背四情形：系统调用/外中断/异常/特权指令违例
- **L2** 每个情形配一个典型例子（fork/时钟中断/缺页/关中断）
- **L3** 反向判断"哪种情形不切态"（普通库函数调用、用户态算术运算）
- **L4** 边界：2022 混合选项（II IO 指令特权+IV 通道硬件技术 vs I/III 错项）
- **L5** 跨章串联：第 2 章 PV 阻塞、第 5 章 I/O 完成
- **预期变形**：给 I/II/III 组合式选项逐项判；给"切换时机"描述挑错
- **陷阱**：把"发生"当"执行"（进程切换只在内核态执行）；把库函数当必然切态

### 中断/异常分类树（S · S-记忆）
- **L1** 背三层树：中断{可屏蔽 INTR/不可屏蔽 NMI}、异常{故障/自陷/终止}
- **L2** 给具体事件归类：缺页=故障、系统调用=自陷、掉电=NMI、除零=故障
- **L3** 判断"缺页属于中断"类假命题（2016）
- **L4** 边界：异常不可屏蔽必须立即处理；故障返回重执行、终止直接杀进程
- **L5** 跨章串联：第 3 章缺页处理流程、组成原理 5.5 中断（C4 同构对照）
- **预期变形**：把 DMA 结束与缺页并置问哪个是异常；给新设备问向量表建立时机（OS 初始化）
- **陷阱**：把"内/外中断"与"软件/硬件中断"两套二分混用；向量表答成链表（2023）

### 系统调用四阶段（S · S-过程）
- **L1** 背四阶段名：传参→陷入→执行服务→恢复返回
- **L2** 排序题（2017 原型 ③②④①）
- **L3** 说明每阶段发生的事（传参内容、保存现场、查表、恢复谁）
- **L4** 边界：硬件与 OS 分工——模式切换/断点保存=硬件；通用寄存器保存/服务例程=OS（2022）
- **L5** 跨章串联：第 2 章 fork、第 4 章 read/write 文件、第 5 章设备请求
- **预期变形**：给缺某阶段的流程挑错；问"调用号何时传递、存于何处"
- **陷阱**：把四阶段答成三段漏"传参"；认为返回必回原调用点（内核可调度别的进程）

### 四特征与互相关（A · S-辨析）
- **L1** 背四特征名与"并发共享最基本"
- **L2** 每特征举一例（时间片轮转/打印机互斥/SPOOLing/进程异步推进）
- **L3** 互相关论证：共享以并发为前提、有效共享提升并发度（2017 原句）
- **L4** 边界：单处理机无真并行；互斥共享资源制约并发度
- **L5** 跨章串联：第 2 章进程并发与临界资源互斥、第 3 章虚拟存储、第 5 章 SPOOLing
- **预期变形**：给"资源管理方式"选项组（互斥/同时访问）判断资源类型；给 SPOOLing 场景问体现了哪两个特征
- **陷阱**：把"并发"答成"同一时刻"；把虚拟只理解为虚存（漏 SPOOLing/CPU 分时）

### 四大管理功能与用户接口（A · S-概念）
- **L1** 背四管理名 + 三类用户接口
- **L2** 给功能描述归入哪个管理（地址映射→存储器管理）
- **L3** 判断"OS 管理源程序内容""OS 提供编译器"类假命题（1.1.4-02/03）
- **L4** 边界：文件管理管组织不管语义；设备管理任务是"为用户"完成"靠系统"
- **L5** 跨章串联：第 2-5 章分别展开四管理
- **预期变形**：给"系统调用/库函数/命令行"三接口混选；问程序接口的本质
- **陷阱**：把库函数与系统调用等同（2010/1.3.6-13 两次设错）；漏 GUI 也属用户接口

### 多道批处理与代价收益（A · S-辨析）
- **L1** 背单道三特征与多道"宏观并行微观串行"
- **L2** 说明 CPU 与 I/O 重叠的机制（中断切道）
- **L3** 收益权衡：利用率/吞吐量↑ vs 交互/响应↓（2017 I/III/IV）
- **L4** 边界：进程多≠利用率高（2022）；无虚存也能多道并发（2022 反例）
- **L5** 跨章串联：第 2 章调度、第 3 章存储管理均源于"多道需解决四问题"
- **预期变形**：给新式 OS 特征反推属单道/多道哪代思想；给"为什么需要中断"配对题
- **陷阱**：把"系统开销小"当多道优点；把分时当多道的子类

### 分时与实时（A · S-辨析）
- **L1** 背分时四特征、实时硬/软二分
- **L2** 给场景归类（订票=软实时、飞控=硬实时、柜台终端=分时）
- **L3** 手算时间片上限（100 进程、响应≤2s → 20ms）
- **L4** 边界：实时允许牺牲利用率；分时改进靠优先级+非抢占（1.2.8-09）
- **L5** 跨章串联：第 2 章调度算法（RR 时间片、实时调度）
- **预期变形**：给响应时间约束反推时间片/调度策略
- **陷阱**：把"加大时间片"当缩短响应；把订票误归硬实时

### 内核与原语（A · S-概念）
- **L1** 背内核两模块来源（硬件紧密+高频）与常驻内存
- **L2** 判断给定功能是否属于内核（时钟管理/中断处理=是；编译器=否）
- **L3** 说明原语原子性的实现（关中断）
- **L4** 边界：原语运行于内核态但内核态执行的不都是原语
- **L5** 跨章串联：第 2 章 PCB 切换原语、第 3 章页表修改特权性
- **预期变形**：给"时钟中断服务程序更新哪些数据"组合判断（2018 I/II/III）
- **陷阱**：把编译器/库函数归入内核功能；认为内核态=只能执行特权指令

### 特权指令清单（A · S-记忆）
- **L1** 背特权清单：IO/置时钟/开关中断/改模式位/清内存/改页表基址
- **L2** 给指令判特权与否（存数、寄存器清零=非特权；1.3.6-08）
- **L3** 判断访管指令归类（用户态可执行、非特权，1.7③）
- **L4** 边界：屏蔽字寄存器属 IO 接口→IO 指令→特权（1.3.6-09）
- **L5** 跨章串联：第 3 章页表基址寄存器、第 5 章设备驱动
- **预期变形**：给 I/II/III/IV 组合问哪组必须内核态执行（1.3.5-02 II+IV）
- **陷阱**：凭"看起来危险"判特权（普通访存也可能缺页但非特权）；把陷入指令当特权
