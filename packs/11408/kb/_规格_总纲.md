# 知识库 · 建模规格总纲（跨学科共用）

> 建档：2026-09-14（v2，替代旧的 `_规格_数学.md`）。**任何 AI 新建/重写 `知识库\` 下章节文件前必读本文件 + 对应学科规格。**
> 学科专属的**粒度判据 / 得分范式 / 文件骨架 / 组合模式**分写在两份：
> - 数学一（高数 / 线代 / 概率）→ `_规格_数学.md`
> - 408（数据结构 / 组成原理 / 操作系统 / 计算机网络）→ `_规格_408.md`
>
> **为什么必须分两份**：11408 是**两个独立专业课**，得分方式不同——数学重**证明与构造**（跳步扣分、构造不出即 0），408 重**过程手算与算法设计**（步骤分、"算法思想 + 代码"双段给分）。粒度、组合方式、验收标准必须各自定义，否则两次建模必然再分叉（这正是 2026-09-14 首轮建模的教训）。

## 二、维护流程（改一章 = 四步）

改知识库只需要引擎本身，不需要额外的建模工具链：

1. **定位**：`kaoyan-mcp validate` 看门禁与账目，`kaoyan-mcp search 关键词` 定位到具体原子，`kaoyan-mcp chapter 科目 章` 读整章。
2. **改写**：按本规格的原子判据与范式改章节文件（A 表 + C 表）。出处必须落到 `{sec}@p{页}`，sec 从 `_目录树\_anchors.tsv` 取，页码一律 PDF 页。
3. **对账**：`kaoyan-mcp reconcile` 按章节文件重算 `_INDEX.md` 的统计（幂等）——别手改统计表，手改迟早再漂一次。
4. **验收**：`kaoyan-mcp validate` 必须 0 FAIL；新增或删除原子后，确认 C 表里的原子链引用仍然成立。

> 建模用的取页工具（把教材 PDF 渲染成页图、由书签生成 `_目录树`）不在本包内：`_目录树\` 已随包提供，
> 需要重新生成时，用你手头的 PDF 工具链按同样的 book / sec / title / page / kind 五列产出 `_anchors.tsv` 即可。

## 三、出处：树锚点 + PDF 页（**硬要求**）

格式：**`{sec}@p{PDF页}`**

| 书 | sec 从哪来 | 例 |
|---|---|---|
| 王道 数据结构 / 操作系统 / 计算机网络 | `_anchors.tsv` 的 `sec` 列（书签精确到小节） | `2.2.3@p47` |
| 王道 组成原理 | 同上（目录页转录，同样到小节） | `3.5.3@p123` |
| 张宇 高数 / 线代 / 概率 | **目录只到讲级** → sec 用**讲内节点名**，从讲首页「基础知识结构」导图读 | `§知识结构图·计算(2)@p28` |

- **唯一判据**：拿到这一格，一条命令能渲染出原文页——
  `python 工具\render-pages.py --book wangdao-co --pdf 123`
- 页码一律 **PDF 页**（7 本都能一键定位）。书页换算只写在文件头。
- **禁止**只写导图页（`P1-2·基础知识结构`）——那是导图**所在**的一页，不是知识点**所在**的页。导图页只能作补充附后。
- **没读到确切页就不许编**：`2.2@p47-52(页待核)`。宁可粗，不可假细。

## 四、证据纪律（不许含糊）

同一格内两类内容必须可区分：

- `【实测 YYYY-MM-DD】`——**真有问答发生**的记录：答了什么、错在哪、判定结果。只许写实际发生过的。
- `【建模推演】`——建模期预判：预期变形、陷阱、易混点、跨节联动。属知识级归纳，**不是实测**。
- 无证据新行：填 `—`。

**铁律**：不得把推演写进 `【实测】`；不得把"我估计他会错"写成"他的弱点"；未开课章节（全 ⬜）不得出现"用户已掌握"。

## 五、工具

本包只依赖包内的 `kaoyan_mcp` 引擎，入口是命令行，也可以按 MCP stdio 起服务：

| 命令 | 作用 |
|---|---|
| `kaoyan-mcp validate` | 质量门禁：结构契约（FAIL）与规格建议（WARN），只读 |
| `kaoyan-mcp reconcile` | 按章节文件重算并回写 `_INDEX.md` 统计（幂等） |
| `kaoyan-mcp search / chapter / atoms` | 检索与读取：一次命中、读整章、原子清单 |
| `kaoyan-mcp overview` | 科目、章节、原子、档位与状态分布 |

## 六、ID 命名与登记

**原子 ID**：`{科码}-{单元号}-{三位序号}` ｜ 例 `GS-01-003`、`DS-02-007`、`CO-03-012`

| 科码 | 学科 |
|---|---|
| `GS` / `XD` / `GL` | 高数 / 线性代数 / 概率论 |
| `DS` / `CO` / `OS` / `CN` | 数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 |

- 单元号：数学 = 讲号两位（`01`–`18`，附录用 `AP`）；408 = 章号两位（`01`–`08`）
- 序号：该单元内从 `001` 起，**按"课堂推进顺序"排**（重要度优先，不按页序）
- **组合 ID**：`C-{科码}-{单元号}-{两位序号}` ｜ 例 `C-GS-06-01`

**ID 铁律**：一经分配**不得复用、不得改号**。删除某原子时其 ID 作废留空，新原子取新号。

**文件名**：数学 `第NN讲_标题.md`；408 `第N章_标题.md`（章名 token 必须含 `第\d+讲` 或 `第\d+章`，校验脚本按此取键）。

## 七、共性验收（建/重写一章后逐条自检）

- [ ] 出处列**每一行**都是 `{sec}@p{页}` 形态，无裸导图页引用
- [ ] 每个原子 ID 唯一、符合 `{科码}-{单元号}-{三位序号}`，且**与本章序号连续无跳号**
- [ ] 每行都有得分范式标签，且取值在该学科规格的允许集合内
- [ ] 每行的"档"都能在第一节分值档里找到对应条目
- [ ] 组合表的每条 `原子链` 引用的 ID **都真实存在于本章原子表**
- [ ] 状态列每行**只有一个**符号（多符号会串统计计数）
- [ ] 推演内容全部带 `【建模推演】`，实测内容全部带 `【实测】`，其余为 `—`
- [ ] 分值档节 / 知识地图节 / 组合表 **不得出现独立成格的状态符号**
- [ ] 跑 `kaoyan-mcp validate` 无 FAIL
