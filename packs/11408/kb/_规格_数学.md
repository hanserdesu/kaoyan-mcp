## 一、数学在 11408 里的得分结构（决定粒度的根）

数一 150 分：**选择 10×5 + 填空 6×5 + 解答 6×10~12**。占比：高数 ≈ 56%（84 分）、线代 ≈ 22%、概率 ≈ 22%。

数学的得分机制与 408 有本质差别，这直接决定原子怎么切：

1. **解答题按步给分，但"第一步不会则后面全 0"**——所以**关键第一步**（选对方法 / 构造出辅助函数 / 认出极限类型）必须独立成原子，不能塞进"会解这道题"里。
2. **选择/填空是全或无**——概念边界与反例必须独立成原子（它是 0 分与 5 分的差别）。
3. **工具性公式是"调用不出就直接卡死"的前置**——常用等价无穷小、常用展开式、Wallis 公式这类要独立成原子，即使它本身"很简单"。

## 二、原子知识点判据（四问全过才成原子）

1. **单问可答**：能写成一个问句，答案是单一断言（定义 / 公式 / 判定 / 步骤）。若答案是"如果…则…否则…"的多分支并列，**拆**。
2. **得分可归**：答不出 → 卷面**明确丢分**。判据不是"书上写了"，而是"考场上这里会扣分"。
3. **不可再拆**：拆开后的碎片不能各自独立成题（只剩符号声明 → 不拆）。
4. **可定位**：能给 `{sec}@p{页}`。

**防碎反向判据**：若两个候选原子在**任何**可能的题里都必然同时出现、从不单独考 → 它们不是两个原子，而是**一个原子 + 一条组合**。这条把"过碎"挡在原子层外，交给第五节处理。

### 数学侧示范（对与错）

| 判 | 例子 |
|---|---|
| ❌ 太粗 | `罗尔定理` → 实际是 3 个原子（三个条件各是什么 / 条件被违反时的反例 / 由结论倒推构造 $F(x)$） |
| ❌ 复合（多分支） | `一阶微分方程的解法` → 拆成可分离 / 齐次 / 线性 / 伯努利 **四个**原子，各自有独立公式与适用判据 |
| ❌ 太碎 | `$e^x$ 的泰勒展开式` 单独成原子？→ 否。它与"常用五个展开式"在任何题里必然同时调用 → 合为一个原子 |
| ✅ 恰当 | `洛必达法则的适用条件（$0/0$ 或 $\infty/\infty$、可导、$\lim f'/g'$ 存在）` ｜ `洛必达失效的情形：$\lim f'/g'$ 不存在**不能**反推原极限不存在` 分两行——后者是选择题专门考的边界 |
| ✅ 恰当 | `$1^\infty$ 型极限的恒等变形 $u^v=e^{v\ln u}$` 与 `七种未定式的识别与归类` 分两行 |

## 三、得分范式（M-*，**必须从中选一个**）

| 代码 | 名称 | 得分机制 | 典型位置 |
|---|---|---|---|
| `M-计算` | 计算求值 | 结果错 = 0（选填）；解答按步给分但中途算错即断 | 全卷 |
| `M-证明` | 证明推导 | 逻辑链分段给分，关键步骤缺失即扣 | 解答题 |
| `M-概念` | 概念真伪判别 | **全或无**，无反悔 | 选择 |
| `M-构造` | 由结论倒推构造（辅助函数 / 反例 / 反推条件） | 构造失败 → 后续全无效 | 解答、选择 |
| `M-建模` | 应用题建模（微元 / 变化率 / 几何物理背景） | 列式分 + 求解分，两项独立 | 解答 |
| `M-记忆` | 公式 / 结论调用 | 调用不出 = 直接卡死（前置工具） | 填空、计算前置 |

- 一个原子**只能有一个**范式。若两种都像 → 说明它该拆成两个原子。
- 旧版的"分型（思路型/计算型/记忆型）"**已被本列取代**，不再保留该列。

## 六、组合考察（C 表）——数学怎么把原子拼成题

**这一节是本规格的核心**：原子只回答"最小可考察单元是什么"，组合回答"考研实际怎么把它拼成一道题"。

| 代码 | 组合模式 | 数学落地 | 反查价值（断此原子 → 整题报废） |
|---|---|---|---|
| `C1` | 同族干扰 | 四选项取同族 3-4 个原子的定义/条件，互为陷阱（如"可导/可微/连续"三者的蕴含关系） | 任一原子模糊 → 该选项误判 |
| `C2` | 链式求解 | 前一步结果是后一步输入，≥3 原子（如"泰勒展开→求极限→判连续"） | **链首原子断 → 后面全 0**（解答题主要失分形态） |
| `C3` | 边界反例 | 给命题判真假 / 举反例（$f'(x_0)=0$ 不必然是极值） | 边界原子不清 → 必错 |
| `C4` | 跨讲串联 | 两个不同讲的原子合考（第 6 讲中值定理 + 第 11 讲积分不等式） | 前置讲原子断 → 整题崩 |
| `C5` | 辨析对比 | 两个易混定理/方法的差异（罗尔 vs 拉格朗日 vs 柯西） | 一个不清 → 答反 |
| `C6` | 建模求解 | 应用题的"列式→求解"两段（微元法、相关变化率、最值建模） | 列式错 → 求解再对也是 0 |

**C 表表头必须逐字一致**：

```
| ID | 组合模式 | 原子链 | 题目形态 | 断点（断此则整题报废） | 真题锚点 |
|---|---|---|---|---|---|
```

| 列 | 规则 |
|---|---|
| ID | `C-{科码}-{讲号}-{两位序号}`，如 `C-GS-06-01` |
| 组合模式 | `C1`–`C6` 之一 |
| 原子链 | `GS-06-003 → GS-06-007 → GS-11-002`，**引用必须真实存在于本章 A 表**（跨讲引用须写明来自哪一讲） |
| 题目形态 | 选择 / 填空 / 解答 / 解答小问 |
| 断点 | 明确指出哪个原子一断则整题报废（这是复习优先级的直接依据） |
| 真题锚点 | 对应 `_考点深度\数学一\<科>_考点深度.md` 的考点行（写"频次×深度"）；无对应则写 `【建模推演】` |

- 每章**至少 4 条、至多 12 条**组合。S 档原子**必须**至少出现在一条组合里（否则它只是"背了没用"）。
- 优先写 `C2`（链式）与 `C6`（建模），因为解答题的失分主要发生在这两类。
