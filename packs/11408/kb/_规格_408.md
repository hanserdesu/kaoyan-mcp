## 一、408 在 11408 里的得分结构（决定粒度的根）

408 满分 150：**单选 40 题 × 2 分 = 80 分 + 综合应用题 7 题 ≈ 70 分**。四科配比 ≈ 数据结构 45 / 组成原理 45 / 操作系统 35 / 计算机网络 25。

408 的得分机制有三个特征，直接决定原子怎么切：

1. **综合应用题按"过程"给分**——Dijkstra 每轮 dist/path 表、哈希表 ASL、B 树分裂、建堆逐次调整、Cache 映射手算：**每一步都有分，断一步扣一步**。所以"手算过程的每一步"必须独立成原子（"能否写出第 3 轮的 dist 数组"就是一个原子）。
2. **算法设计题是双段给分**——"算法思想"占一部分、"代码实现"占一部分。**两段必须拆成两个原子**（会讲思想但写不出代码，与反过来，是两种不同的失分）。
3. **选择题是全或无，且专考边界**——判空/判满条件、下标从 0 还是 1、溢出判断、协议字段位数。这些"边界条件"本身就是独立原子。

## 二、原子知识点判据（四问全过才成原子）

1. **单问可答**：能写成一个问句，答案是单一断言（定义 / 公式 / 判定 / 步骤 / 一行代码）。多分支并列 → **拆**。
2. **得分可归**：答不出 → 卷面**明确丢分**。判据是"考场上这里扣分"，不是"书上写了"。
3. **不可再拆**：拆开后的碎片不能各自独立成题。
4. **可定位**：能给 `{sec}@p{页}`（408 四本的 sec 都能精确到小节）。

**防碎反向判据**：若两个候选原子在**任何**可能的题里都必然同时出现、从不单独考 → 它们是**一个原子 + 一条组合**，不是两个原子。
**防粗判据（408 特有）**：任何"需要分步执行才有分"的过程，**每一步都要问一次"这一步能不能单独考"**——能，就必须拆出来。

### 408 侧示范（对与错）

| 判 | 例子 |
|---|---|
| ❌ 太粗 | `Dijkstra 算法` → 实际是 4-5 个原子：算法前提（非负权）/ 逐轮 dist 更新规则（松弛）/ 已确定集合 S 的维护 / path 前驱记录 / 手算表格的填法 |
| ❌ 太粗 | `链表插入删除` → 拆成：头插法 / 尾插法 / 中间插入的指针次序（先接后断）/ 带头结点与不带头结点的判空与边界 / 删除时释放与断链顺序 |
| ❌ 混两段 | `线性表就地逆置算法设计题` → 拆成 **「算法思想（双指针/三指针的交换次序）」** 与 **「关键代码（循环边界与语句次序）」** 两个原子——双段给分，失分点不同 |
| ❌ 太碎 | `单链表判空条件` 与 `双链表判空条件` 分成两个原子？→ 保留两个（它们是 C1 同族干扰的经典选项，且判错方向相反） |
| ✅ 恰当 | `循环队列判满条件 (rear+1)%M==front 与判空条件 rear==front 的区别` ｜ `循环队列元素个数公式 (rear−front+M)%M` 分两行 |
| ✅ 恰当 | `Cache 三种映射方式的地址划分（标记/行号/块内偏移各占几位）` ｜ `Cache 容量与地址位数的换算步骤` 分两行 |
| ✅ 恰当 | `拓扑排序的序列个数统计` 与 `拓扑排序的算法步骤` 分两行——前者是手算计数，后者是算法描述 |

## 三、得分范式（S-*，**必须从中选一个**）

| 代码 | 名称 | 得分机制 | 典型位置 |
|---|---|---|---|
| `S-过程` | 过程手算（表 / 树 / 逐轮迭代） | **步骤分，断一步扣一步**——过程对才有分 | 综合应用题、选择题 |
| `S-算法` | 算法设计（思想描述 + 代码实现） | **思想分 + 代码分两段**，可各得部分 | 综合应用题 |
| `S-概念` | 概念真伪 / 边界判别 | 全或无（2 分） | 单选 |
| `S-结构` | 结构与量化分析（复杂度 / 容量 / 地址 / 时序 / 位数） | 结果错即 0，重在算对 | 单选、综合题小问 |
| `S-辨析` | 两方案 / 两结构的取舍对比 | 全或无 | 单选 |
| `S-记忆` | 术语 / 层次结构 / 公式直接调用 | 命中即得 | 单选 |

- 一个原子**只能有一个**范式。两种都像 → 该拆成两个。
- 旧版的"分型（思路型/计算型/记忆型）"**已被本列取代**，不再保留该列。

## 六、组合考察（C 表）——408 怎么把原子拼成题

**这一节是本规格的核心**：原子只回答"最小可考察单元是什么"，组合回答"考卷实际怎么把它拼成一道题"。408 有 **7** 种组合模式（比数学多一种：算法设计题）。

| 代码 | 组合模式 | 408 落地 | 反查价值（断此原子 → 整题报废） |
|---|---|---|---|
| `C1` | 同族干扰 | 四选项取同族 3-4 个原子（判空条件、存储结构特性、协议字段），互为陷阱 | 任一原子模糊 → 该选项误判 |
| `C2` | 链式求解 | 前一步结果是后一步输入（虚存→TLB→Cache→主存逐级地址映射；取指→译码→执行→写回） | **链首断 → 后面全 0** |
| `C3` | 边界反例 | 判空/判满、下标 0 起还是 1 起、溢出判断、栈满时入栈 | 边界原子不清 → 必错 |
| `C4` | 跨章串联 | 跨章/跨科合考（组成原理 Cache ↔ 操作系统虚存；数据结构 图 + 排序） | 前置章原子断 → 整题崩 |
| `C5` | 辨析对比 | 顺序表 vs 链表 / CISC vs RISC / 中断 vs 异常 / TCP vs UDP | 一个不清 → 答反 |
| `C6` | 过程手算 | 建表 / 建树 / 逐轮迭代 / 逐趟序列（Dijkstra 表、ASL、B 树分裂、建堆） | **首步建错 → 全错**；中途断 → 只扣断点之后 |
| `C7` | 算法设计（408 独有） | 思想描述一段 + 代码一段，双段给分；常带隐藏约束（O(1) 空间 / 原地 / 不破坏原结构） | 思想段拿不到 → 代码段也难给分 |

**C 表表头必须逐字一致**：

```
| ID | 组合模式 | 原子链 | 题目形态 | 断点（断此则整题报废） | 真题锚点 |
|---|---|---|---|---|---|
```

| 列 | 规则 |
|---|---|
| ID | `C-{科码}-{章号}-{两位序号}`，如 `C-DS-06-02` |
| 组合模式 | `C1`–`C7` 之一 |
| 原子链 | `DS-06-003 → DS-06-007 → DS-06-011`，引用必须真实存在于本章 A 表（跨章引用须注明章号） |
| 题目形态 | 选择 / 综合应用题 / 综合题小问 |
| 断点 | 明确指出哪个原子一断则整题报废（复习优先级的直接依据） |
| 真题锚点 | 对应 `_考点深度\408\<科>_考点深度.md` 的考点行（写"频次×深度"）；或直接引书里的具体题页 |

- 每章**至少 4 条、至多 16 条**组合。S 档原子**必须**至少出现在一条组合里。
- **每章必须至少 1 条 `C6`（过程手算）和至少 1 条 `C7`（算法设计，仅数据结构/操作系统适用；组成原理/计网用 `C6`+`C2` 补足）**——这是 408 大题的两种主要形态。
- `C6` 的原子链要写清**手算对象的粒度**（"第 k 轮"而不是"整个过程"）。

## 七、学习阶梯与陷阱（第六节）：S/A 档专属

```
### {原子名}（{档} · {得分范式}）
- **L1** {入门：定义 / 识别}
- **L2** {基本用法：标准流程 / 直接代入}
- **L3** {变形：换规模 / 换边界 / 换结构}
- **L4** {边界与陷阱：失效条件 / 反例 / 下标与判空}（参考章末「常见问题和易混淆知识点」@p{页}）
- **L5** {跨章串联：与哪一章哪一原子合考（写出原子 ID）}
- **预期变形**：{真题级改法 1-3 条}
- **陷阱**：{判错点 1-3 条}
```

- 节首必须有：`> 证据等级：知识级推演（{建模日期} 建模），非实测。`
- 过程型（`S-过程`）的原子，L2/L3 要写成"手算演练的层级"（单轮 → 多轮 → 带陷阱的规模）。
- 算法型（`S-算法`）的原子，L2/L3 要**分开写思想与代码两层**。
- 未开课章（全 ⬜）**禁止**写"用户已掌握 X"。
