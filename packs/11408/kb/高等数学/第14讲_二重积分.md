- **S（年频大题或考得深）**：本讲无单列 S 档；几何应用和换元均作为计算链中的工具或 B 档材料处理。

## 二、本书定位（考点 / 题型 / 目标 / 重难点）

- **考点**：二重积分的概念与性质、对称性、直角坐标与极坐标计算、交换积分次序、二重积分换元、古鲁金第二定理。
- **题型**：选择题、填空题、解答题。
- **目标**：理解二重积分的概念、基本性质和中值定理；掌握直角坐标、极坐标下的计算方法；能根据区域边界重画并交换积分次序。
- **重难点**：平面区域 D 的识别与分割；先判断对称性和坐标系，再正确写出积分上下限；换元时同时处理区域、被积函数和雅可比。

## 三、知识地图（讲首页结构图叶子，原始层级）

### 二重积分的概念与性质

分割与黎曼和 → 几何意义 → 基本性质 → 中值定理 → 区域比较与参数区域。

### 对称性

普通对称性（坐标反射与奇偶性）→ 轮换对称性（$x\leftrightarrow y$）→ 平均化简。

### 二重积分的计算

直角坐标系下的 X 型 / Y 型区域 → 交换积分次序；极坐标系下的区域与面积元 → 直角/极坐标互换 → 一般换元与雅可比。

### 几何应用与区域识别

古鲁金第二定理 → 形心与旋转体体积；直角坐标直线/曲线边界型 → 极坐标方程型 → 参数方程型。

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 区域选择与二重积分性质（A · M-建模）

- **L1** 能解释二重积分的区域、被积函数和正负面积意义。
- **L2** 用保号、估值和中值定理处理给定区域。
- **L3** 题目允许选区域时，按 $f$ 的符号决定纳入哪些子域；参数变化时比较区域面积和函数量级。
- **L4** 陷阱：把一条性质的前提搬到另一条性质；最大积分题把负值区域也纳入；把中值定理中的点当成可直接求出的固定点。
- **L5** 串联 GS-14-008、GS-14-009、GS-14-011、GS-14-012。
- **预期变形**：由区域包含关系比较积分；将被积函数改成带参数的符号变化函数；把区域最大化与椭圆边界结合。

### 普通与轮换对称性（A · M-计算）

- **L1** 画出区域并判断关于坐标轴、原点或 $y=x$ 的不变性。
- **L2** 检查被积函数在相同变换下是偶、奇还是需要与交换式平均。
- **L3** 对复杂区域先用辅助曲线分割，再叠加对称结论。
- **L4** 陷阱：只满足函数奇偶而区域不对称；把轮换对称误写成关于坐标轴对称；交换 $x,y$ 后忘记同时交换区域。
- **L5** 串联 GS-14-013、GS-14-014、GS-14-015、GS-14-016。
- **预期变形**：给出半圆、扇形或差集区域；把 $f(x,y)$ 改成 $f(x,y)+f(y,x)$；要求比较两个对称子域的积分符号。

### 直角坐标计算与交换次序（A · M-计算 / M-建模）

- **L1** 识别 X 型、Y 型区域，正确写出一层变量和外层变量。
- **L2** 画区域后把一组累次积分改写成另一组次序。
- **L3** 遇到无初等原函数、参数上限或边界切换时，主动重画区域并分割。
- **L4** 陷阱：只交换 $dxdy$ 而不交换上下限；曲线交点遗漏；反向积分的负号在重画区域时丢失。
- **L5** 串联 GS-14-017、GS-14-018、GS-14-019、GS-14-020、GS-14-021、GS-14-044。
- **预期变形**：把积分次序隐藏在函数定义里；增加一条切割线使区域必须拆分；把换序结果继续用于求导。

### 极坐标计算与坐标互换（A · M-计算 / M-建模）

- **L1** 写出 $x=r\cos\theta,y=r\sin\theta,d\sigma=r\,dr\,d\theta$。
- **L2** 根据原点位置和区域草图确定角度范围、径向下限和上限。
- **L3** 将圆、直线、椭圆或极坐标曲线的边界转成可积的 $r(\theta)$，再完成径向积分。
- **L4** 陷阱：原点在区域外却从 $r=0$ 积；角度范围多扫或漏扫；换了被积函数但漏乘 $r$；同一边界被重复计数。
- **L5** 串联 GS-14-023、GS-14-024、GS-14-025、GS-14-026、GS-14-027、GS-14-028、GS-14-029。
- **预期变形**：把直角坐标区域改成极坐标方程型；让积分跨越多个象限；要求在两种坐标表达之间选择更短的计算链。

### 一般换元与雅可比（A · M-计算 / M-建模）

- **L1** 认出新变量的目标结构和对应的变换关系。
- **L2** 逐项替换函数、区域和面积元，计算雅可比绝对值。
- **L3** 通过 $u=x+y$、$v=y$ 等线性换元把三角形或比值结构化为简单区域。
- **L4** 陷阱：只换被积函数不换区域；忘记雅可比绝对值；雅可比为零或映射多对一时直接套公式。
- **L5** 串联 GS-14-030、GS-14-031、GS-14-032、GS-14-033。
- **预期变形**：给出椭圆或斜带区域；让换元同时承担边界简化和被积函数简化；把极坐标作为验证特例。

### 区域识别、分割与参数讨论（A · M-建模）

- **L1** 从不等式中读出基本边界并画草图。
- **L2** 求曲线交点，确定每条切片的上下界。
- **L3** 按临界参数、对称性、差集或 $y=x$ 分割区域，再把每块写成直角或极坐标积分。
- **L4** 陷阱：用代表参数替代全参数讨论；忽略包含关系改变；画出边界却没有判断不等式取哪一侧；$\max$ 或绝对值没有按分界线拆开。
- **L5** 串联 GS-14-038、GS-14-039、GS-14-040、GS-14-041、GS-14-042、GS-14-043。
- **预期变形**：将一个区域改成两圆差集；让参数经过相切值；把选择题图形改成含参数解答题。
