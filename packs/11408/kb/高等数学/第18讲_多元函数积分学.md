## 一、分值档（S/A/B）

> 依据 `..\_考点深度\数学一\高等数学_考点深度.md`（知识级归纳，P2 逐题回填后修正）。分级施加：S 全强度（why 链 + 变形 + 串联），A 常规验收，B 口测/一句话带过。

- **S（年频大题核心，深度全强度）**：第二类曲线积分 + 格林公式（含补线、奇点剔除；档案"年频（大题）·深"）；曲线积分与路径无关、势函数（档案"年频·深"）；第二类曲面积分 + 高斯公式（含补面；档案"年频（大题）·深"）。三大公式是档案"考得深"清单主战场。
- **A（年频·中-深）**：三重积分（直角、柱面、球面坐标，档案"年频·中-深"）；第一类曲线积分（档案"年频·中"）；第一类曲面积分（档案"年频·中"）；斯托克斯公式（档案"隔年·中-深"）。
- **B（偶考/浅，口测即可）**：散度、旋度（场论初步，档案"偶考·浅"，填空直接套定义）；重积分与线面积分的几何、物理应用（档案未单列，按应用口径归 B）。

> 说明：本讲 S 档三大簇（格林链、路径无关、高斯链）是数一解答题的固定大题来源，且每簇内部"构造（补线／补面／挖洞）→ 公式 → 化低维积分"强耦合，故原子层按"每一种构造手法"与"公式前提"拆开。A 档斯托克斯按档案"隔年"处理；B 档散度、旋度按档案"偶考·浅"只做口测级。

## 二、本书定位（讲首页 p494 考纲表）

- **考点**：三重积分、第一型曲线积分、第一型曲面积分、第二型曲线积分、第二型曲面积分
- **题型**：选择题、填空题、解答题
- **目标**：① 理解三重积分的概念，了解三重积分的性质；② 会计算三重积分（直角坐标、柱面坐标、球面坐标）；③ 理解两类曲线积分的概念，了解两类曲线积分的性质及两类曲线积分的关系；④ 掌握计算两类曲线积分的方法；⑤ 掌握格林公式并会运用平面曲线积分与路径无关的条件，会求二元函数全微分的原函数；⑥ 了解两类曲面积分的概念、性质及两类曲面积分的关系，掌握计算两类曲面积分的方法，掌握用高斯公式计算曲面积分的方法，并会用斯托克斯公式计算曲线积分；⑦ 会用重积分、曲线积分及曲面积分求一些几何量与物理量（平面图形的面积、体积、曲面面积、弧长、质量、质心、形心、转动惯量、引力、功及流量等）
- **重难点**：① 第二型曲线积分；② 第二型曲面积分；③ 格林公式；④ 高斯公式；⑤ 斯托克斯公式

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 第二型曲线积分·格林公式三情形（S · M-构造）
- **L1** 复述格林公式与两前提（正向边界、一阶连续偏导）与三情形识别（封闭无奇点 / 非封闭补线 / 有奇点挖洞）
- **L2** 封闭无奇点：验证条件→套公式→化二重积分（例18.17）
- **L3** 非封闭补线（例18.18）；有奇点挖同向小圆换路径（例18.19）；路径无关定参后折线法（例18.20/18.21）
- **L4** 边界与陷阱：**未验条件直接套 = 0 分**；补线方向与减号；挖洞反向答案反号；非单连通域等价链失效
- **L5** 跨讲串联：GS-17 系列预备知识（平面/直线/曲面方程定限）、GS-14 二重积分计算、GS-18-005 路径无关链
- **预期变形**：① 变力做功建模（C-GS-18-01）；② 含参 P、Q 先定参再验证（例18.21）；③ 与路径无关联考折线/原函数两法互验
- **陷阱**：① 漏减补线段；② 挖洞半径取错分母代换后漏系数；③ 把"除奇点外散度/偏导恒零"当成"处处连续"

### 第二型曲面积分·高斯公式三情形（S · M-构造）
- **L1** 复述高斯公式与两前提（外侧、一阶连续偏导）与三情形识别（封闭 / 非封闭补面 / 有奇点挖面）
- **L2** 封闭外侧：套公式→三重积分→奇偶轮换对称化简（例18.26）
- **L3** 非封闭补平面（例18.27）；奇点挖小球面、分母代曲面方程（例18.28）；转换投影兜底（例18.25）
- **L4** 边界与陷阱：**内侧忘变号 = 0 分**；补面方向与减号双断点；换面异侧断；直投三 dxdy 同名不同义
- **L5** 跨讲串联：GS-18-016 三重积分对称性、GS-18-019/020 柱球坐标算 dv、GS-18-039 两类曲面积分联系
- **预期变形**：① 通量物理背景题（考纲目标⑦）；② 对称性先筛再套公式省计算；③ 被积式含 $(x^2+y^2+z^2)^{3/2}$ 型挖洞后代球面方程
- **陷阱**：① 补面取侧反向；② 挖洞后忘代曲面方程直接积分；③ 把第一型 dS 当第二型 dxdy 用

### 三重积分·坐标选择（A · M-计算）
- **L1** 复述四种坐标适用域形（直角任意 / 柱面圆域锥域 / 球面球锥 / 换元椭球）
- **L2** 先对称性筛（奇倍零、轮换）→选坐标→定限→算
- **L3** 先二后一识别（只含 z、圆截面）；广义球坐标雅可比
- **L4** 边界与陷阱：**柱面漏 r²、球面漏 r²sinφ**；φ 从 z 轴起算；换元 J 取绝对值
- **L5** 跨讲串联：GS-18-010/011/012（高斯化三重积分后必用）、GS-14 二重积分
- **预期变形**：① 抛物面 z=4(x²+y²) 截圆柱（习题18.8 型）；② 椭球域广义球坐标（例18.5）
- **陷阱**：① 投影域画错；② 截面法用在不只含 z 的函数上

### 一投二代三计算（A · M-计算）
- **L1** 三类积分各自"一投二代"核心：一型曲线定积分（ds 三式）、一型曲面二重积分（dS）、二型曲面三项投影
- **L2** 平面显式 / 参数式 / 极坐标 ds 选择（例18.8/18.9）
- **L3** 空间参数式（例18.10 轮换先行）；柱面 dS=a dθdz（例18.12）；转换投影（例18.25）
- **L4** 边界与陷阱：**ds 漏根号即断**；二型"起点对应下限"；投影重合必须分片；二型投影为线则该项为零
- **L5** 跨讲串联：GS-17 预备知识参数方程、GS-18-042 统一对称口诀
- **预期变形**：① 一型先轮换对称化简再算（习题18.1/18.5）；② 二型直投与转换投影互验（例18.22 两解法）
- **陷阱**：① 用第一型无向思路做第二型；② 极坐标 ds 用成 √(r²+1)dθ

### 斯托克斯公式（A · M-记忆）
- **L1** 复述两种形式（行列式二型形式 / 第一型形式）与右手系
- **L2** 空间闭曲线→选易算曲面片→套公式（例18.30 方法二）
- **L3** 与格林公式辨析（平面特例）；参数法兜底（方法一）
- **L4** 边界与陷阱：**曲面片选错（非张在 Γ 上）即断**；行列式行序与 n° 对应错
- **L5** 跨讲串联：GS-18-001（平面特例）、GS-18-028（第一型曲面积分计算承接）
- **预期变形**：① 平面圆域化二重积分快速版（习题18.3 方法二）；② 两种形式按计算量选
- **陷阱**：① 忘验 Γ 与 Σ 方向右手系；② 行列式里把 n° 行与偏导行放错
