## 二、本书定位（考点 / 题型 / 目标 / 重难点）

- **考点**：向量代数；空间解析几何与曲面方程（平面、直线、曲面、空间曲线及投影）
- **题型**：选择题、填空题、解答题
- **目标**：① 理解向量的概念，掌握向量的线性运算、数量积、向量积，了解混合积，掌握两向量垂直、平行的条件；② 理解曲面方程的概念，掌握常用二次曲面的方程及其图形，会求以坐标轴为旋转轴的旋转曲面方程及母线平行于坐标轴的柱面方程，会求空间曲线在坐标面上的投影；③ 掌握平面方程和直线方程及其求法，会利用平面、直线的相互关系（平行、垂直、夹角）解决有关问题
- **重难点**：① 向量积、混合积的坐标计算及其几何意义（面积 / 体积 / 共面）；② 旋转曲面、柱面与投影柱面/投影曲线的求法（第 18 讲前置）；③ 平面与直线方程的建立及位置关系判定

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 向量积、混合积与共面判定（A · M-计算）
- **L1** 复述向量积行列式展开与右手方向；混合积 = 先叉乘再点乘
- **L2** 给坐标算 $\vec a\times\vec b$ 与混合积；算平行四边形、平行六面体
- **L3** 变形：三角形面积（½）、四面体体积（1/6）、四点共面判定
- **L4** 边界与陷阱：体积忘取绝对值；四点共面要先化成三条连线向量
- **L5** 跨讲串联：GS-17-025（法向量构造）、第 18 讲第二类曲面积分的法向量与侧
- **预期变形**：① 给四点求四面体体积；② "是否存在 λ 使三向量共面"型含参题
- **陷阱**：① 行列式展开符号错；② 把混合积直接当体积（漏绝对值）

### 数量积与垂直/平行判据（A · M-概念）
- **L1** 复述定义、坐标式、夹角公式
- **L2** 用数量积为 0 判垂直、坐标成比例判平行
- **L3** 变形：含参向量垂直/平行求参数；投影定理互推
- **L4** 边界与陷阱：零向量与任何向量"平行"；向量夹角范围 $[0,\pi]$
- **L5** 跨讲串联：GS-17-005、GS-17-026、GS-17-030（位置关系判据同一引擎）
- **预期变形**：① 求参数使两平面垂直；② 方向余弦平方和为 1 的隐含条件题
- **陷阱**：① 平行判据对零向量失效的情形；② 夹角公式漏绝对值

### 旋转曲面与柱面方程（A · M-记忆）
- **L1** 复述规则：绕哪个轴哪个坐标不动，另一坐标换成另两坐标平方和开方（带 ±）
- **L2** 给 $f(x,y)=0$ 求绕 x 轴 / 绕 y 轴的旋转面
- **L3** 变形：由旋转面方程反推母线；含参曲线旋转
- **L4** 边界与陷阱：± 号漏写；绕轴记反；柱面"缺谁平行谁"
- **L5** 跨讲串联：GS-17-014、GS-17-016（二次曲面可看作旋转面/柱面的演化）
- **预期变形**：① 抛物线绕对称轴得旋转抛物面；② 判断给定方程是否旋转面
- **陷阱**：① 把"绕 x 轴"做成另一坐标替换到 x；② 柱面方程当成空间曲线

### 常见二次曲面识别（A · M-记忆）
- **L1** 报出六种标准方程与名称
- **L2** 方程 → 图形、图形 → 方程互认
- **L3** 变形：配方化标准形；判断含参方程类型
- **L4** 边界与陷阱：单叶/双叶双曲面差一项符号；椭圆抛物面与双曲抛物面（马鞍面）
- **L5** 跨讲串联：GS-17-013、第 18 讲积分区域的曲面识别
- **预期变形**：① 截痕法定性描述图形；② 给交线判断立体形状
- **陷阱**：① 双曲面两种类型混淆；② 忽略平方项系数正负

### 投影两步法（A · M-计算）
- **L1** 复述两步：消元 → 投影柱面；补 $z=0$ → 投影曲线
- **L2** 球面与平面（锥面）交线在 xOy 面投影的完整计算
- **L3** 变形：消 x / 消 y 得另两个坐标面的投影；参数曲线投影
- **L4** 边界与陷阱：**只写柱面不补 $z=0$ 不叫投影曲线**；漏变量范围限制
- **L5** 跨讲串联：GS-17-020、GS-17-023、第 18 讲三重积分投影法与曲面积分投影
- **预期变形**：① "求投影柱面"与"求投影曲线"分开问（答案不同）；② 立体在坐标面上的投影区域（不等式组）
- **陷阱**：① 忘补 $z=0$；② 把整条柱面曲线当作交线（漏范围）；③ 消元平方项处理出错引入假点

### 法向量构造与建平面（A · M-构造）
- **L1** 复述点法式与法向量概念
- **L2** 三种构造：两点连线加一点叉积、取已知直线方向向量、$\vec n_1\times\vec n_2$
- **L3** 变形：过一点垂直于两已知平面；平行平面族
- **L4** 边界与陷阱：法向量差非零倍数等价；过原点无截距式
- **L5** 跨讲串联：GS-17-025、GS-17-037、第 18 讲曲面法向量与高斯公式
- **预期变形**：① 由"与两平面夹角相等"建平面；② 求交线在坐标面上的投影直线
- **陷阱**：① 法向量取错（用了不垂直的向量）；② 把"垂直于直线"误做成平行

### 直线方程互化与位置关系（A · M-计算）
- **L1** 复述三式与方向向量
- **L2** 一般式 → 对称式（取 $\vec n_1\times\vec n_2$ 加找点）；对称式 → 参数式
- **L3** 变形：线线/线面夹角；判平行、垂直、重合
- **L4** 边界与陷阱：线面角公式用 $\sin$ 不是 $\cos$；分母为 0 约定；平行与重合需再取点验证
- **L5** 跨讲串联：GS-17-029、GS-17-030、GS-17-036
- **预期变形**：① 直线与曲面交点；② 点到直线距离（叉积法）
- **陷阱**：① 把线面角余弦当正弦；② 互化时找的点不满足方程组
