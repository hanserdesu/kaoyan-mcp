## 二、本书定位（讲首页 p145 考纲表）

- **考点**：极值点与单调性、拐点与凹凸性、最值等函数性态的分析，渐近线的求法
- **题型**：选择题、填空题、解答题
- **目标**：① 理解函数的极值概念，掌握用导数判断函数的单调性和求函数极值的方法，掌握函数最大值和最小值的求法及其应用；② 会用导数判断函数图形的凹凸性，会求函数图形的拐点以及水平、铅直和斜渐近线，会描绘函数的图像；③ 了解曲率、曲率圆与曲率半径的概念，会计算曲率和曲率半径（仅数学一、数学二）
- **重难点**：① 极值点的判别；② 拐点的判别

## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 方程根的个数（S · M-构造 / M-计算）
- **L1** 识别题型：方程 $f(x)=0$ 或 $f(x)=a$ 的根个数，"有几个 / 讨论参数范围"
- **L2** 标准流程：求 $f'(x)$ → 定单调区间与极值（最值）→ 算端点 / 无穷远趋势 → 用零点定理与介值性数交点
- **L3** 含参变形：分离参数为 $a=g(x)$，转成"水平线 $y=a$ 与 $y=g(x)$ 交点个数"；或直接讨论 $f(x)=a$
- **L4** 边界：分界值取在极值 / 最值处（$a$ 等于极值时重根）；有界区间须与端点值比较；渐近线决定无穷远有无交点
- **L5** 跨讲串联：第 1 讲零点定理与介值性、本讲 GS-05-003（判单调）与 GS-05-031（最值定分界）、第 6 讲中值定理（构造 $F$ 证根存在）
- **预期变形**：① 讨论 $\ln x-ax=0$ 在 $(0,+\infty)$ 的根的个数（分离参数按 $a$ 分区间）；② 给"有且仅有两根"反求参数范围；③ 讨论 $x^3+px+q=0$ 的实根个数（按极值符号分类）
- **陷阱**：① 只凭零点定理判"存在"不判"个数"（须配单调性）；② 忘算端点 / 无穷远趋势导致漏交点；③ 分界值算在极值处，但忽略参数使驻点个数本身变化

### 单调性与极值（A · M-概念 / M-计算）
- **L1** 复述极值定义、必要条件（费马定理）与第一 / 第二充分条件
- **L2** 直接流程：求 $f'$ → 定驻点与**不可导点** → 用第一充分条件（$f'$ 变号）或第二充分条件（$f''$ 符号）判极值
- **L3** 含参 $f'$ 符号讨论（按参数分类）；隐函数 / 参数方程求极值；由关系式反推 $f''(x_0)$ 符号（例5.5）
- **L4** 边界与反例：$f'(x_0)=0$ 不必然是极值（$x^3$）；$f''(x_0)=0$ 时第二充分条件失效，退回第一充分条件；不可导点（$\lvert x\rvert$）也是候选
- **L5** 跨讲串联：第 3/4 讲导数计算与隐函数 / 参数求导、本讲 GS-05-001/002（根个数）、第 6 讲中值定理
- **预期变形**：① 含参 $f$ 讨论极值点个数；② 由 $f''+[f']^2=\sin x$ 判某点极值 / 拐点（例5.5）；③ 隐函数方程求极值并验证
- **陷阱**：① 漏不可导点；② 用第二充分条件未先验 $f'(x_0)=0$；③ 把必要条件当充分条件

### 凹凸性与拐点（A · M-概念 / M-计算）
- **L1** 复述凹 / 凸定义（弦与弧比较、切线与曲线位置）、拐点定义与必要条件（$f''(x_0)=0$ 或不存在）
- **L2** 直接流程：求 $f''$ → 找 $f''=0$ 与不存在点 → 用第一充分条件（$f''$ 变号）判拐点
- **L3** 多项式 $f=\prod(x-a_i)^{n_i}$ 用结论③数拐点个数；含参讨论拐点个数
- **L4** 边界与反例：$f''(x_0)=0$ 不必然是拐点（$x^4$）；拐点处 $f''$ 不存在也可能（$\sqrt[3]{x}$）；拐点只需连续、不要求可导
- **L5** 跨讲串联：第 4 讲二阶导计算、本讲 GS-05-020（可导点不可同时为极值点与拐点）、第 6 讲凹凸性用于不等式证明
- **预期变形**：① 判 $f=(x-1)^2(x-3)^3$ 的拐点个数（例5.8）；② 求凹凸区间与拐点坐标（须写 $(x_0,f(x_0))$）；③ 由微分方程关系式判拐点（例5.5）
- **陷阱**：① $f''(x_0)=0$ 直接判拐点（须验变号）；② 拐点只写横坐标；③ 把"拐点在曲线上"误解为"在 $x$ 轴上"

### 渐近线（A · M-计算 / M-概念）
- **L1** 复述三类渐近线定义与判别式（铅直 / 水平 / 斜）
- **L2** 标准流程：先找无定义点 / 端点 / 分段点 → 铅直 → 水平（两侧分别）→ 斜（$a,b$ 都算）
- **L3** $x\to\pm\infty$ 结果不同时分侧求（$y=\arctan x$、例5.9）；一条曲线可同时有多类渐近线
- **L4** 边界：只求出 $a$ 不能定斜渐近线（$b$ 不存在则无，$y=x+\sin x$）；同侧水平渐近线存在时无斜渐近线
- **L5** 跨讲串联：第 1 讲极限计算（求渐近线即求极限）、本讲作图与性态分析、间断点分类（无穷间断点 ↔ 铅直渐近线）
- **预期变形**：① 求 $y=\frac{x^2+x}{x^2-1}$ 的渐近线条数（习题5.3）；② 求 $y=(2x-1)e^{1/x}$ 的斜渐近线（习题5.7）；③ 含 $\ln(1+e^x)$ 型分侧求（例5.9）
- **陷阱**：① 漏算 $b$（只写 $y=ax$）；② 忘查 $x\to-\infty$ 一侧；③ 把有定义的点误作铅直渐近线候选（须极限为 $\infty$）

### 闭区间 / 实际最值（A · M-计算）
- **L1** 复述最值定义，区分最值与极值
- **L2** 标准流程：求 $(a,b)$ 内驻点与不可导点函数值 → 算端点值 → 比较取最值
- **L3** 开区间 / 无界区间用单侧极限替代端点值；实际应用题先建立目标函数并定定义域
- **L4** 边界：实际问题的目标函数有唯一极值点即为最值；开区间可能无最值
- **L5** 跨讲串联：本讲 GS-05-008/009（判极值）、第 10 讲积分应用（面积/体积最值，待建）
- **预期变形**：① 求 $x+2\cos x$ 在 $[0,\frac\pi2]$ 的最大值（习题5.6）；② 求 $\{\sqrt[n]{n}\}$ 的最大项（例5.10）；③ 几何 / 物理量最值建模（面积、周长、成本）
- **陷阱**：① 忘比端点值；② 实际题未验证"唯一极值点即最值"就直接用；③ 定义域取错（漏约束）
