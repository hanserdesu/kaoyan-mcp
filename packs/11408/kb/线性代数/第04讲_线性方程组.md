## 一、分值档（S/A/B）

> 依据 `..\_考点深度\数学一\线性代数_考点深度.md`（知识级归纳，P2 逐题回填后修正）。分级施加：S 全强度（why 链 + 变形 + 串联），A 常规验收，B 口测/一句话带过。档案导言：**大题几乎固定在"方程组解的结构"或"相似对角化/二次型"两处轮转**，且必然与向量组线性相关性、秩绑定考查——本讲是线代大题两大轮转点之一。

- **S（档案"年频（大题）"或"年频·深"行）**：齐次方程组解的结构——有解条件（列满秩只有零解 / 不满秩 $n-r$ 个自由变量）、解的性质（解的线性组合仍是解）、基础解系三条件与构造三要点（个数 $n-r$、行列式 $\ne0$ 保无关、$\xi$ 与行向量正交）、求解五步流程（档案行 1：**年频（大题）·深**，"大题主体；基础解系要写全且线性无关"）；非齐次方程组解的结构与通解——有解条件三条（$r(A)\ne r(\bar A)$ 无解 / $=n$ 唯一 / $=r<n$ 无穷多）、解的性质（$\eta_1-\eta_2$ 是导出组解、$k\xi+\eta$ 是非齐次解）、特解 + 齐次通解合成（档案行 2：**年频（大题）·深**）；含参数方程组的解判定——两个不同解 $\Rightarrow|A|=0$、按参数分支讨论并舍根（档案行 3：**年频·深**，"按行列式为零/非零分支，别漏 $\det=0$ 的特殊值"）。
- **A（偶考但深度"深"，或年频跨讲落点）**：同解方程组与公共解——三条等价刻划（互相含解 / 秩相等且一方解满足另一方 / 三秩相同）、公共解三方法（联立 / 代入 / 通解相等）、含参同解讨论（档案行 4：**偶考·深**，"证明两方程组同解（互相包含）"）；由解向量反推参数与表示关系（例 4.9/4.11，档案行 1/2 的大题第一问落点）；抽象方程组求通解（例 4.10 ★★★ 注：齐次解 = 使列组合为零的系数、非齐次解 = $\beta$ 的表示系数，挂档案第 3 讲"线性相关/无关"行 **年频（大题）·深**）；解的个数 $=n-r$（例 4.3，挂档案行 1）；矩阵方程转非齐次求解（习题 4.9，挂档案行 2）；秩的夹逼判定（习题 4.6，挂档案第 2 讲"矩阵秩"行 **年频·深**）。
- **B（偶考中档或概念铺垫，口测即可）**：方程组与几何的应用（三平面位置关系，档案行 5：偶考·中）；方程组与向量组同一性的概念行；非齐次求解流程的机械步骤；消去律 $AB=AC\Rightarrow B=C$（列满秩类）；正交向量转齐次方程组（例 4.2）；行满秩必有解与 $A^TAx=A^Tb$ 必有解（例 4.6/4.7）；基础解系的线性变换组（例 4.5）；$A^Tx=0$ 与 $[A^T;b^T]x=0$ 同解的易错点（例 4.14）；四秩相同（例 4.15 注）；习题概念行（4.1/4.4/4.5）。

> 说明：档案行 4"同解、公共解"是偶考，但深度标"深"（证明两方程组同解 = 互相包含的双向论证），且例 4.13-4.15 是一整条含参同解链——按 A 处理而非 B。档案行 5"三平面"档案未挂具体年份且深度"中"，按 B 口测。其余归 A/B 的判据在对应行备注列标 `【建模推演】`。

## 二、本书定位（考点 / 题型 / 目标 / 重难点）

- **考点**：本讲无考纲表（线代分册无此栏目）；讲目标从 p121 讲首「基础知识结构」导图读出。
- **题型**：选择（解的判定与性质、公共解/同解概念）、填空（含参判定、通解结构）、解答（**大题主体**：齐次求解 + 基础解系、非齐次通解、含参讨论、抽象方程组、同解证明）。
- **目标**（自 p121 导图）：① 理解齐次线性方程组：有解的条件、解的性质、基础解系和解的结构、求解方法与步骤（导图标注 ★★★）；② 理解非齐次线性方程组：有解的条件、解的性质、求解方法与步骤；③ 会求两个方程组的公共解；④ 掌握同解方程组。
- **重难点**（自教材标注与例题分布）：基础解系必须写全且线性无关（例 4.1 三要点）；非齐次通解 = 特解 + 齐次通解（例 4.8/4.9）；含参讨论不漏 $\det=0$ 的特殊值且要舍根（例 4.8）；抽象方程组的翻译（例 4.10 ★★★ 注）；同解方程组三条刻划（例 4.13-4.15 一条链）。

## 六、学习阶梯与陷阱（S/A 档）

### 齐次方程组求解与基础解系（S · M-计算）
- **L1** 复述三条件定义（XD-04-006）与通解形式（XD-04-007）
- **L2** 五步流程走一遍（XD-04-008）：行变换 → 阶梯定 $r$ → 自由变量 → 基础解系 → 通解
- **L3** 构造三要点（XD-04-009）：个数 $n-r$、$\lvert[\xi]\rvert\ne0$ 保无关、$\xi$ 与行向量正交；变形题——$A^*x=0$（XD-04-012）、线性变换组（XD-04-013）、由正交条件反求（XD-04-010）
- **L4** 边界与陷阱：**基础解系没写全（个数不足 $n-r$）= 结构性丢分**；自由变量取法不唯一但个数唯一（XD-04-038）；只能行变换（XD-04-037）
- **L5** 跨讲串联：XD-03-010（第 3 讲判定链）、XD-03-026（$r(A^*)$）、第 2 讲初等行变换
- **预期变形**：① 例 4.3 型"有几个线性无关解"；② 例 4.4 型伴随方程组；③ 习题 4.8 型具体求解
- **陷阱**：① 个数算错（$n-r$ 用成 $n$ 或秩）；② 特解自由变量取值导致线性相关；③ 行最简形回代抄错系数

### 非齐次通解结构（S · M-计算 / M-概念）
- **L1** 复述三条有解条件（XD-04-014）与解的性质（XD-04-015）
- **L2** 标准合成（XD-04-016）：导出组通解 + 一个特解
- **L3** 抽象版：由已知解向量构造（XD-04-020，系数和 $=0/1$）；抽象方程组翻译（XD-04-021，★★★注）
- **L4** 边界与陷阱：**$r(A)\ne r(\bar A)$ 判无解是第一动作**；两个非齐次解的组合一般不是解（系数和 $=1$ 才是）；特解取法不唯一
- **L5** 跨讲串联：XD-04-017（行满秩必有解）、XD-03-011（第 3 讲表示存在性判据）、第 2 讲秩
- **预期变形**：① 例 4.8 型含参收尾；② 例 4.9 型由解向量反推通解；③ 习题 4.9 型矩阵方程
- **陷阱**：① 忘加特解；② 把非齐次解的差当非齐次解；③ 通解里 $k$ 的个数与 $n-r$ 不符

### 含参方程组判定（S · M-计算）
- **L1** 齐次侧：$\lvert A\rvert\ne0$ 唯一零解 / $=0$ 无穷多解（XD-04-040）；非齐次侧：两个不同解 ⇒ $\lvert A\rvert=0$（XD-04-019）
- **L2** 分支回代：参数取特殊值后**必须重新行变换**比较 $r(A)$ 与 $r(\bar A)$
- **L3** 舍根论证：增广秩更大的参数舍去（例 4.8 的 $\lambda=1$），保留的参数求出通解
- **L4** 边界与陷阱：**别漏 $\det=0$ 的特殊值**（档案原文）；含参行列式展开因式分解错则分支全错；舍根不写理由扣分
- **L5** 跨讲串联：XD-04-014（有解条件）、XD-04-002/003（齐次侧）、克拉默法则（第 1 讲）
- **预期变形**：① 双参数讨论（例 4.8 的 $\lambda$ 与 $a$）；② 判定 + 求通解两问连做；③ 习题 4.10 型"对任意 $C$ 成立 ⇒ 系数为零"
- **陷阱**：① 只讨论 $\ne0$ 分支；② 特殊值回代时不再算秩；③ 通解没写到 $n-r$ 个 $k$

### 抽象方程组与解的构造（A · M-构造）
- **L1** ★★★注复述：齐次解 = 使列组合为零的表示系数；非齐次解 = 表示 $\beta$ 的系数（XD-04-021）

- **L3** 由解向量构造通解：系数和 $=0$ ⇒ 齐次解、$=1$ ⇒ 特解（XD-04-020）；矩阵求逆反解
- **L4** 边界与陷阱：**翻译方向搞反整题报废**（C-XD-04-04 断点）；无关性需验证（$\eta_1-\eta_2$ 与 $3\eta_1+\eta_2-4\eta_3$ 无关要证）
- **L5** 跨讲串联：XD-03-006/010（相关性）、XD-04-022（由通解反推秩）
- **预期变形**：① 例 4.11 型四选项反推；② 习题 4.7 型公共解定参；③ 换一组表示关系的同型题
- **陷阱**：① 把"$\beta$ 的表示系数"当齐次解；② 构造的解不验证无关性；③ 系数和判据用反

### 同解与公共解（A · M-概念 / M-计算）
