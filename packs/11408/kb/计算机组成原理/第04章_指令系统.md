**复习提示**（p160）：指令系统是表征一台计算机性能的重要因素。应掌握各种寻址方式的特点及有效地址的计算，三种偏移寻址（相对寻址、基址寻址和变址寻址）的地址计算方法，以及 CISC 与 RISC 的特点与区别。2022 年大纲新增机器级表示相关内容，而机器级代码题型在历年统考中多次出现，需具备读懂汇编代码的能力。本章知识点既可能出选择题，也可能结合其他章节出有关指令的综合题。指令格式、机器指令、寻址方式与 CPU 指令执行过程密切相关，需重点掌握。

**本章目标**：① 能对扩展操作码做各长度指令条数的逐层分配与容量反推；② 能对十种数据寻址写出 EA 公式与访存次数，并完成相对转移目标手算；③ 能读懂 x86 汇编段，完成 C 语句与汇编互译、标志位判断与栈帧分析。

## 六、学习阶梯与陷阱（S/A 档）
> 证据等级：知识级推演（建模期归纳），非实测。
### 扩展操作码容量计算（S · S-过程）
- **L1** 规则：短操作码不能是长操作码前缀、各指令操作码不重复（CO-04-001）
- **L2** 正向分配：留扩展前缀 → 每层剩余 = (2^k − 已用) × 2^地址码位数（图4.1：15+15+15+16=61）
- **L3** 反推：给各层条数求指令字长/某层最多条数（2017 题13：29 三地址 → OP 5 位 → 23 位 → 字节编址取 24）
- **L4** 边界与陷阱：扩展操作码**不改变指令长度**（解析 08）；零地址层整层倍数勿漏（2022 题15=128 条）
- **L5** 跨章串联：CO-04-024 定长容量对照；第 5 章指令译码器按操作码分发控制信号
- **预期变形**：给总指令数与部分层条数求剩余层；双解法（逐层减法 vs 整层乘法）互验
- **陷阱**：短码占用了长码前缀空间；某层「最多」与「恰好」混淆；忘记字节编址向上取整对齐
### 十种寻址的有效地址与访存次数（S · S-结构）
- **L1** 背表 4.1（CO-04-002）：立即 0 / 直接 1 / 间接 2 / 寄存器 0 / 寄存器间接 1 / 相对·基址·变址各 1（不含取指）
- **L2** 给指令求 EA 与总访存次数；区分「取指令」是否计入（CO-04-006 含取指口径并存）
- **L3** 复合寻址：先变址后间址 EA=((I)+D)（2016 题28）；变址+相对混合
- **L4** 边界与陷阱：一次间接 vs 二次间接访存次数；寄存器寻址不算访存；立即寻址最快（题05）
- **L5** 跨章串联：第 3 章 Cache 命中率改写「有效访存次数」；第 5 章取操作数微操作序列
- **预期变形**：四种寻址方式按执行速度排序；按寻址特征字段逐条分析指令（2020）
- **陷阱**：把间接寻址算进偏移寻址（2011 题24）；基址变址 EA 公式相同但可变对象相反
### 相对转移目标地址计算（S · S-过程）
- **L1** 公式：目标 = (PC) + 偏移，PC = 取指完成后已自增的值（CO-04-003）
- **L2** 字节编址 2 字节指令：PC_after = PC + 2；偏移补码符号扩展（2009 题23：2000H+2+06H=2008H）
- **L3** 变形：偏移单位为指令条数（2013 综合04：PC+2+2×OFFSET=1FD4H）；3 字节指令双字节偏移小端拼装（题18）
- **L4** 边界与陷阱：编址单位（字编址 PC+1，4.2.4 综合01）×指令字长×偏移单位三参数组合；向后转移负偏移补码
- **L5** 跨章串联：第 5 章转移指令微操作（PC←PC+offset）同式
- **预期变形**：给机器码反推偏移量与目标；给目标反推偏移字段（题18 的 2F/00 与 D5/FF）
- **陷阱**：用取指前的 PC 计算（漏自增）；偏移单位按字节却按字算；忘记补码符号扩展
### 机器级代码综合分析（S · S-过程）
- **L1** 识别指令类别：传送/算逻/移位/控制流（CO-04-004）；认识 AT&T 与 Intel 两种语法（CO-04-029）
- **L2** 单条执行：lea 做乘加（CO-04-019）、cmp/test 设标志不存结果（CO-04-018）、imul/idiv 隐含寄存器（CO-04-017）
- **L3** 段级映射：if-else 模板（CO-04-023）、循环转 do-while（CO-04-030）、call/ret 栈帧（CO-04-020/021）
- **L4** 边界与陷阱：有符号/无符号转移判据（CO-04-005）；mem→mem 禁忌（CO-04-015）；16 字节栈对齐（CO-04-010）
- **L5** 跨章串联：第 5 章微操作序列、第 3 章虚拟地址→物理地址→Cache 映射（4.3.6 解析 03/04 原型）
- **预期变形**：给 C 片段写汇编；给汇编还原 C 结构；手算执行后寄存器/内存/标志位；判断溢出与异常（2025 idiv 异常）
- **陷阱**：把 lea 当访存；把指针比较当有符号；忽略 GCC 16 字节对齐填充
### 指令格式字段与访存次数（A · S-结构）
- **L1** 指令 = 操作码 + 地址码；零～三地址指令的功能与形态（CO-04-006）
- **L2** 位数分配：OP 位数 + 地址码位数 ≤ 指令字长；寄存器编号位数 = log2(寄存器数)（2021 综合05）
- **L3** 变形：给操作数类型（寄存器/立即数/内存）求各格式指令长度（4.1.6 综合01：18/23/34/29 位）
- **L4** 边界与陷阱：一地址 ACC 型 3 次访存 vs 二地址 4 次（含取指口径）；A 位数与寻址范围对应（CO-04-008）
- **L5** 跨章串联：第 3 章主存容量与 MAR/MDR 位数（2021 综合05）
- **预期变形**：定长 vs 变长指令字的空间开销对比（省 25% 计算）
- **陷阱**：寄存器寻址误算访存；立即数范围按无符号算
### 指令寻址与 PC 自增（A · S-概念）
- **L1** 顺序寻址 (PC)+指令字长；跳跃寻址由转移指令改 PC（CO-04-007）
- **L2** 按字节编址：16 位指令 PC+2、32 位 PC+4；按字编址 PC+1（2013/2014/2019/2023 四年考点）
- **L3** 变形：取指令 vs 取数据访存区分；绝对转移 vs 相对转移判断
- **L4** 边界与陷阱：条件转移是否转移由条件码决定；跳跃后 PC 不再加指令字长
- **L5** 跨章串联：第 1 章 CO-01-016（取指后 PC 自动加 1）的精确化
- **预期变形**：给 PC 初值与指令序列求最终 PC；中断返回时 PC 恢复
- **陷阱**：把「+1」理解为 1 字节；跳跃指令本身也占指令字长
### 基址 vs 变址（A · S-辨析）
- **L1** 共同点：EA = 寄存器内容 + 形式地址，均属偏移寻址（CO-04-009/011）
- **L2** 基址：BR 由 OS 设定执行期间不变、A 用户可变、利于多道程序重定位
- **L3** 变址：IX 用户动态修改（下标）、A 固定（数组首址）、适合循环（题29：顺序访问一维数组选变址）
- **L4** 边界与陷阱：可变对象在两种寻址中对称相反；题30 由 EA 差反求下标（double 8B：100H/8=32）
- **L5** 跨章串联：操作系统多道程序重定位（基址）、数组与循环（变址）
- **预期变形**：给应用场景选寻址方式；基址+变址复合；4.6 问 1 七方式适用情况配对
- **陷阱**：把「基址寄存器内容可变」记成偏移可变；数组场景误选基址
### 大小端与边界对齐（A · S-结构）
- **L1** 大端 MSB 在低地址；小端 LSB 在低地址（CO-04-010）
- **L2** 多字节数据：指令只给起始地址、CPU 按类型连续读（4.6 问 2）；x86 小端（题11：R1=7856H）
- **L3** 变形：EA 手算后定位 LSB 地址 = EA+(字节数−1)（题19/31）
- **L4** 边界与陷阱：GCC 16 字节栈对齐（28B→32B）；内存地址无符号（题31 的 A=FF12H 补码换算）
- **L5** 跨章串联：第 2 章数据存储（2.3 节考纲注）、第 3 章主存访问
- **预期变形**：给机器数与地址求数值；判断存放次序图
- **陷阱**：大端小端方向记反；把偏移当无符号（FF12H 实为 −00EEH）
### call/ret 与栈帧（A · S-过程）
- **L1** call 压返回地址再转移；ret 弹出返回地址转移（CO-04-020）；六步调用序列
- **L2** 栈帧：EBP 固定基址、[ebp±offset] 访问；ESP 动态；leave = mov esp,ebp + pop ebp（CO-04-021）
- **L3** 变形：调用者/被调用者保存寄存器归属；参数入栈次序（左参数低地址/先压后参）
- **L4** 边界与陷阱：push 先减后写、pop 先读后加（CO-04-016）；返回地址 = call 下一条指令地址
- **L5** 跨章串联：第 5 章堆栈型 CPU 与中断现场保存；操作系统进程切换
- **预期变形**：给栈帧图填内容；递归调用的栈帧叠加（2019 综合02 n!）
- **陷阱**：EBP/ESP 角色互换；调用者保存与被调用者保存归属记反
### CISC vs RISC（A · S-辨析）
- **L1** 表 4.3 十行对比（CO-04-022）：重点行 = 指令数、字长、访存限制、控制方式、流水线
- **L2** RISC 四优势：芯片面积（硬布线约 10% vs 微程序 50%+）、速度、易设计、利编译
- **L3** 变形：给机器级代码判断 CISC/RISC（2017 综合01：变长指令 → CISC）
- **L4** 边界与陷阱：RISC 必然流水线、流水线未必 RISC（题01）；RISC 兼容性反而差；LOAD/STORE 原则（CO-04-032）
- **L5** 跨章串联：第 5 章硬布线 vs 微程序控制器同源
- **预期变形**：给叙述判断是否符合 RISC（2009/2025 统考连考）
- **陷阱**：「指令功能强」当 RISC 特点（题02）；「格式种类多利于编译优化」说反（题04）
### ISA 边界与条件转移标志位（A · S-辨析）
- **L1** ISA 规定四条内容（CO-04-013）；微架构实现（乘法器/微程序/数据通路）不在 ISA 内

- **L4** 边界与陷阱：漏 ZF 条件（相等时误转）；指针比较按无符号（CO-04-023 的 jbe）
- **L5** 跨章串联：第 2 章溢出判断（SF⊕OF）同源；第 5 章条件码寄存器
- **预期变形**：if(a>b) 与 if((unsigned)a>b) 的汇编差异；imul 溢出处理（2019 综合02 问 5）
- **陷阱**：把 OF 用于无符号比较；把 CF 用于有符号比较
