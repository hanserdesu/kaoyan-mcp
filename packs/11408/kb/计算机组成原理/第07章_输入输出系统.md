## 六、学习阶梯与陷阱（S/A 档）

> 证据等级：知识级推演（建模期归纳），非实测。

### 三种 I/O 方式 CPU 时间占比计算（S · S-过程）
- **L1** 识别三方式：查询（CPU 执行程序轮询）、中断（外设主动通知、指令边界响应）、DMA（硬件直传、仅预处理后处理占 CPU）
- **L2** 标准代入：查询占比=次数×每次指令×CPI÷主频；中断占比=次数×（响应+服务）÷主频；DMA 占比=次数×（预处理+后处理）÷主频
- **L3** 变形：换缓冲宽度（32 位=4B）、换速率单位（MB/s vs kb/s vs b/s）、换题问法（最长查询间隔=1/最低频次、至少占比 vs 最多占比）
- **L4** 陷阱：分子分母对账——中断/DMA 请求响应时机（指令边界 vs 总线周期结束）决定「每秒次数」上限；「最长延迟」不进占比分子（2014 题39）；DMA 分子只含预处理+后处理（参考 7.5@p338-339 易混点）
- **L5** 跨章串联：2012 综合08 一题串 CO-03（Cache/多体交叉）+本章；设备速率计算与 CO-01 性能指标（CPI/MIPS）联动
- **预期变形**：给 b/s 速率先换字节（9600b/s=1200B/s，2022 综合05）；串行帧加起始/校验/停止位（2016 综合09）；周期挪用下 64 位缓冲拆总线请求次数（2022 综合11）
- **陷阱**：把 DMA 数据传送段也计入 CPU 占用；忘记缓冲填满时间=4B÷速率（按字而不按字节算）；中断方式「至少占比」与「最长延迟」混用

### 中断处理全链路与多重中断（S · S-过程）
- **L1** 背出九步框架：隐指令（关中断/保存断点/寻址）+服务程序（保存现场/开中断/执行/关中断/恢复/开中断返回）
- **L2** 标准排序题：单重中断序（无⑤⑦）；区分硬件做（①~③）与软件做（④~⑨）
- **L3** 变形：由屏蔽字表反推处理优先级并画执行轨迹（例7.3、2022 综合04）；由处理优先级写某源的屏蔽字（2011 题35）
- **L4** 边界与陷阱：响应优先级硬件固定、处理优先级屏蔽字可调（2024 题52）；被屏蔽请求不进判优电路；嵌套仅在服务程序执行段开中断时发生（2017 题41）；断点=指令边界（故障类异常例外，见 CO-07-017）
- **L5** 跨章串联：异常分类与第 5 章 5.5（CO-05-081 系列）同源；多重中断与 OS 中断处理（内核态切换）合考
- **预期变形**：五级中断源给响应序+处理序写屏蔽字；给执行轨迹反推屏蔽字；隐指令与断点保存的硬件/软件归属判断
- **陷阱**：「屏蔽字决定响应优先级」（错，决定处理优先级）；「向量地址=入口地址」（错，是入口地址的地址）；「中断处理期间 CPU 一直关中断」（错，执行段开中断）

### I/O 接口与端口编址（A · S-辨析）
- **L1** 分清接口（物理部件）与端口（接口内可寻址寄存器）；三类寄存器读/写权限
- **L2** 标准对比：独立编址（专用 IN/OUT、地址空间独立）vs 统一编址（访存指令、占主存空间）
- **L3** 变形：给场景判编址方式（是否需要专用指令、地址是否与主存重叠）；判信息走哪类总线线（数据/地址/控制）
- **L4** 边界与陷阱：状态/控制寄存器可合用端口（读/写方向区分）；中断类型号走数据线而请求/响应走控制线；统一编址 I/O 地址不能任意放
- **L5** 跨章串联：I/O 指令=特权指令与 OS 内核态联动；端口编址与第 3 章存储器地址空间合考
- **预期变形**：2017 题16（I/O 指令传送发生在通用寄存器与端口间）；2018 题40（打印场景哪些信息经端口交换）
- **陷阱**：「接口=端口」；「独立编址下端口地址不能与主存相同」（可以相同）；「统一编址须专用 I/O 指令」（错，用访存指令）

### DMA 传送方式与过程（A · S-辨析）
- **L1** 背 DMA 控制器六件套与三阶段（预处理→传送→后处理）
- **L2** 标准对比：三方式适用场景与 CPU 利用率排序（停止访存最低、交替访存最高）
- **L3** 变形：周期挪用单字粒度（每字占用一个存储周期）；缓冲宽度→总线请求次数（512B÷8B=64 次）
- **L4** 边界与陷阱：周期挪用≠整块期间 CPU 不能访存（2020 题47）；DMA 请求在总线周期结束响应而非指令结束；DMA 与 CPU 冲突时 DMA 优先（防丢数据）
- **L5** 跨章串联：DMA 传输通路（设备接口↔主存）与第 6 章总线事务合考；DMA 结束中断与本章中断链合考
- **预期变形**：2022 综合11（扇区字段位数+平均访问时间+DMA 请求次数三连问）；2025 题54/55（DMA 适配设备+结束触发外中断）
- **陷阱**：「CPU 执行 DMA 传送程序」（错，硬件完成）；「DMA 中断服务程序也须保存现场」（无须，不占 CPU 寄存器）；「DMA 结束不产生中断」（后处理正是靠中断通知）
